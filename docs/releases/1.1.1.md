## Direct replies to delegating agents

- Date and author: 2026-11-03; Codex.
- Authority: The deploying user explicitly requested that agents assigned tasks or asked questions respond directly to the delegating agent every time.
- Deficiency and affected rule: SCP-NEG-005 required delivery but left responsibility for forwarding nested-chat output unclear. The replacement explicitly requires each reply to reach the immediate requesting agent, using an authorised messaging tool or channel when nested-chat output is not routed there by the host.
- Necessity: Amending the existing delivery rule avoids a new core rule. Naming questions, intermediate replies, each delegation level, and the actual sending step closes ambiguities that a shorter instruction to “reply directly” would leave unresolved.
- Compatibility: Compatible with the existing local delivery obligation and unchanged message and record formats; makes sender responsibility explicit. The fetched canonical main still identifies itself as v1.1.0. These edits do not publish or adopt the local v1.1.1 contract; adoption requires authorised canonical publication and explicit peer agreement. Historical interpretations remain unchanged.
- Files: [PROTOCOL.md](../../PROTOCOL.md), this amendment note.
